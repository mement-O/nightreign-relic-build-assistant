# Nightreign Relic Build Assistant

v1.1.3（日本語／English）。PC版セーブの所持遺物から、プリセット最適化・遺物編成検索・追加スキル検索を行うブラウザツールです。

v1.1.1では開始戦技・開始魔術／祈祷の表示名称から「※適用可能な武器種のみ」とその直前の改行を削除しました。効果一覧の通常効果は種別の接尾辞を付けず、深層効果のみ「（深層）」を表示します。適用ルール・識別キーは従来どおりです。

[ツールを開く](https://mement-o.github.io/nightreign-relic-build-assistant/)

## 言語切替 / Language

画面右上の「日本語」「English」で切り替えます。言語はこのブラウザに保存されます。検索条件・除外設定・検索結果・マイセットは切替前の状態を保持します。効果名の検索は日本語・英語のどちらでも利用できます。英語名称が未収録の効果・遺物は日本語で表示します。プリセット名・マイセット名・プレイヤー名は翻訳しません。

Use **日本語 / English** at the top of the page. Language is remembered in this browser. Conditions, exclusions, results and saved builds are preserved when switching languages. Effect filters accept Japanese and English. Names missing from the English data remain in Japanese. User-defined names are kept unchanged.

旧版の評価対象外・デメリット除外は初回読込時に固定IDへ移行します。管理方法と検証範囲は [docs/localization.md](docs/localization.md) を参照してください。

## 使い方

1. 「セーブを読み込む」でPC版のセーブ（.sl2 / .co2）を選択します。複数のセーブ枠がある場合は所持遺物が最も多い枠を自動選択します。
2. 「プリセット最適化」では登録済み構成の遺物を選び、改善候補を確認できます。正式マスタに基づき、異ランクの重複や左側優先の競合も判定します。
3. 「遺物編成シミュレーター」ではキャラクターと付けたい効果を指定します。指定値は完全一致で判定し、未指定のメリット効果は許容します。器の所持状況にかかわらず、キャラクターの全器を対象にします。
4. 「追加スキル検索」は、現在の検索条件から追加・強化できる効果を探します。候補を選択すると検索条件へ反映します。
5. 結果の詳細から構成に名前を付けて保存できます。「マイセット」で閲覧・上下移動・削除でき、同一構成は検索結果でも強調されます。

## 検索モードと絞り込み

- 高速検索：50件または100件で打ち切ります。上限到達時は、ほかにも結果がある可能性があります。
- 全件検索：すべての成立構成を探します。ただし2万件または60秒で安全停止します。通常検索の60秒停止は高速検索にも適用されます。
- 両検索ボタンは実行中に「検索中断」になります。中断・安全停止時は取得できた結果だけを残し、完了と区別します。追加スキル検索は手動で中断できます。
- 検索結果は50件ずつ表示します。メリット・デメリットの一覧は、取得した全ページの結果から集計します。未取得の構成は集計に含みません。
- メリット除外：チェックをまとめて選び「適用して再検索」を押します。一つでも指定効果が有効な構成を除外します。左側優先で無効な効果は判定しません。ランク・通常／深層は別項目です。
- 検索条件に指定済みの効果枠は、メリット除外候補に表示しません。除外中の項目は0件になっても残り、解除できます。「閉じる」は未適用の変更を破棄します。
- デメリット除外：選択を次回検索へ反映します。追加スキル候補を表示している場合は自動更新します。メリット除外の適用でも、表示中の追加スキル候補を更新します。
- 検索条件を変更すると、そのキャラクターの除外設定はリセットされます。
- 「評価対象外」は最適化の評価と検索条件の候補を管理する設定です。その効果を含む構成自体を除外する機能とは異なります。

## 保存・対応範囲

セーブの解析はブラウザ内で行い、セーブへの書き込みや外部送信は行いません。ゲーム内の装備は手動で変更してください。

読み込んだ遺物情報、設定、マイセットは同じサイト・ブラウザのlocalStorageに保存します。他端末や別ブラウザには同期されません。サイトデータを削除すると消えます。マイセットは保存時点の構成を保持し、最新セーブで遺物が一致しない場合はその旨を表示します。同一構成の判定はプレイヤー名・セーブ枠・キャラクター・器・遺物の順序と効果に基づきます。

色・通常／深層を判定できない遺物は警告し、推測して検索候補へ登録しません。器の色構成とスロット順序で検索します。器一覧の表示順はゲーム内と一致しない場合があります。

検索時間は所持数・効果の組み合わせ・条件・端末に左右されます。所持上限に近い1,999個のセーブでの全件検索性能は未確認です。対応マスタの出典は [docs/data-sources.md](docs/data-sources.md)、日本語版の確認範囲は [docs/release-ja.md](docs/release-ja.md) を参照してください。

## ファイル構成・開発

- `index.html`：画面構造と説明
- `assets/app.js`：セーブ読込・評価・検索・保存処理
- `assets/ui.js`：分類表示・フィルター表示・スクロール補助
- `assets/styles.css`：画面スタイル
- `assets/i18n.js`：表示翻訳・言語設定（検索判定には使用しない）
- `assets/locale-en.js`：英語UI文言
- `data/names.en.json`：英語の効果名・遺物名
- `data/effect-identities.json`：固定効果ファミリーIDと旧設定の移行表
- `data/effect-rule-master.json`：適用範囲・重ね掛け・上限の正式ルール
- `data/effect-base-master.json`：遺物名・効果名・EffectGroup・ランク
- `data/relic-struct.json`：遺物IDごとの色・通常／深層
- `docs/`：出典・保守・リリース記録

HTTPサーバーで配信してください。`file://`ではJSON読込が動作しません。公開先はGitHub Pagesです。
