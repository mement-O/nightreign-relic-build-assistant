# 保守メモ

## v24の整理方針

v23hの読込経路を追跡し、実際に適用される補正を含むマスタを保存した。JavaScriptは復号・展開後の処理を引き継ぎ、遺物マスタの起動時検証をbootstrapからapp.jsへ移した。UI拡張とCSSは従来の順序を維持して結合した。保存済み設定のキー・形式は変更しない。

過去のruntimeディレクトリ、旧UI、圧縮部品、bootstrap、実行時ルール補正は現行構成から削除。今後、マスタを変更する際はdata内のJSONへ直接反映し、後付け補正は追加しない。

## 完了：Q4 多言語化（v1.1.0）

同一効果のランク違い・通常／深層はまとめて評価対象外にする仕様。v1.1.0で評価対象外とデメリット除外を固定識別キーへ移行し、旧設定の引き継ぎと日英切替を追加した。今後の識別子の保守・名称データの扱いは [localization.md](localization.md) を参照。

## 検証範囲

整理前後で3マスタの内容を全件比較する。検索の完全一致、追加スキル、デメリット除外、B2/Q2の補正、Q5の非同期無効化を回帰テストする。圧縮方式を廃止するため配置ファイルのバイト数は増えるが、履歴ファイル削除の目的は構成の明確化であり、ダウンロード速度の向上を保証するものではない。
