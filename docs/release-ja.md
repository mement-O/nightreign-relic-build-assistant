# 日本語版 v1.0.0 の基準

## 内容

v26の機能を日本語版の基準として固定。開発段階の名称・古い版情報を整理し、使い方、検索上限、途中終了、ブラウザ保存の説明を整備した。

再読込でキャラクターが変わった際、そのキャラクターの検索条件へ正しく切り替える修正を含む。プリセット未登録時の検索キャラクターは追跡者を初期選択する。検索完了で0件の場合は条件の見直しを案内する。

正式マスタ3ファイル、最適化ロジック、Organizerは変更していない。保存設定の既存キーを維持する。

## 確認範囲

- 正式マスタと最適化：同一効果の別ID、通常／深層、UNIQUE_LEVELの異ランク保持、ADDITIVE、NON_STACKING、4分類のLEFTMOST_WINS、復讐者の戦技・魔術競合。
- 検索：完全一致、+0基準の換算、追加スキルの新規・強化、デメリット除外、除外された先頭候補の後にある成立候補の探索。
- 非同期：検索中のキャラクター・条件・セーブ・評価対象外変更で古い結果が混入しない。
- マイセット：保存・重複判定・並び替え・削除・再読込・プロフィールの分離。
- v26の実セーブ由来データと指定6条件：高速50/100件、全件1,005件。メリット除外、無効な競合効果の許容、追加スキル列挙への除外適用。
- v26のブラウザ操作：ページ切替、全取得結果の候補集計、除外後0件から解除、未適用変更の破棄、中断。
- 日本語版の再読込：キャラクター切替時の条件参照の回帰テスト。

実セーブの内容や検証用データは公開ファイルに含めない。最大所持数の全件検索性能や全ブラウザでの動作を保証する検証ではない。

## 継続事項

- 多言語化時は、評価対象外・デメリット除外など表示名依存の設定を固定識別子へ移す。既存設定を引き継ぐ。
- マスタ内の器名など、元から英語のデータ名は今回翻訳していない。
- 全件検索が安全停止する実例が得られた場合、その条件を基に性能対策を検討する。
